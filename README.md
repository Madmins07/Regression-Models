## about

Two regression models written from scratch in NumPy, with the gradient descent loop visible rather than hidden
inside a library call.

## notebooks

| notebook | what it does | open |
|:--|:--|:--|
| [`Linear_regression_scratch.ipynb`](Linear_regression_scratch.ipynb) | Lot area against sale price from a house-price dataset: feature scaling, cost function, gradient descent, fitted line. | <a href="https://colab.research.google.com/github/Madmins07/Regression-Models/blob/main/Linear_regression_scratch.ipynb"><img src="https://colab.research.google.com/assets/colab-badge.svg" alt="Open in Colab"/></a> |
| [`logistic_regression_from_scratch.ipynb`](logistic_regression_from_scratch.ipynb) | Titanic survival on five features: sigmoid, log loss, gradient descent, accuracy on the test set. | <a href="https://colab.research.google.com/github/Madmins07/Regression-Models/blob/main/logistic_regression_from_scratch.ipynb"><img src="https://colab.research.google.com/assets/colab-badge.svg" alt="Open in Colab"/></a> |

## data

The linear notebook downloads its CSV from a URL. The logistic notebook expects the Kaggle Titanic files
(`train.csv`, `test.csv`, `gender_submission.csv`) next to it; get them from
[kaggle.com/c/titanic](https://www.kaggle.com/c/titanic/data).
